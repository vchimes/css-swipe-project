## Swipe Project - TailwindCSS Edition

**Live Site:** [vchimes.github.io/css-swipe-project](https://vchimes.github.io/css-swipe-project/)

This is the final project for _The HTML & CSS Bootcamp Edition_ course by Colt Steele via Udemy. Its purpose is to employ various design techniques, such as:

- Flexbox & Grid
- Positioning
- Reusable cards
- TailwindCSS features like @theme, @apply, & @layer base/components for customization and vanilla CSS features (grid-template-areas in particular)
- Animations & gradients

It was built with gh-pages and Vite, despite having no React components.

Instead of using vanilla CSS and following the course exactly, I instead chose to use TailwindCSS for this project. The codebase is pretty messy, with every element in the HTML. This was done intentionally as a learning experience. The site is only optimized for desktop - no responsive design was implemented.
